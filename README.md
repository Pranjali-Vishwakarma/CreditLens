# CreditLens

**Explainable Credit Risk & Loan Approval Simulator** — CA-2 coding assignment for *AI in Banking and Finance* (Symbiosis Institute of Technology, Pune).

Given a loan applicant's financial and personal attributes, CreditLens scores credit risk using an XGBoost classifier, explains the decision with SHAP, and audits for age-band disparate impact using fairlearn — all inside a Streamlit UI that runs fully offline on CPU.

---

## Setup

```bash
git clone <repo-url>
cd CreditLens

python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

> **Dataset**: German Credit Data is downloaded automatically from the UCI ML Repository on first run of `preprocess.py`. No manual download needed.

---

## Usage

Run modules in order for a fresh environment, or skip to `streamlit run` if processed data and model already exist.

| Command | What it does |
|---|---|
| `python src/preprocess.py` | Download & process raw data → `dataset/processed/` |
| `python src/train.py` | Train XGBoost model → `models/credit_model.pkl`, prints metrics |
| `python src/explain.py` | SHAP explanation on test sample → prints dict + saves `docs/global_shap_summary.png` |
| `python src/fairness.py` | Fairness audit by age band → prints group metrics + disparate impact flags |
| `streamlit run src/app.py` | Launch full interactive app at `http://localhost:8501` |
| `pytest tests/ -v` | Run test suite (21 tests) |

## Model Performance

Trained on 800 records (80/20 stratified split). XGBoost baseline with no hyperparameter tuning.

| Metric | Value |
|---|---|
| Accuracy | 0.7550 |
| Precision (default class) | 0.6170 |
| Recall (default class) | 0.4833 |
| F1 (default class) | 0.5421 |
| ROC-AUC | 0.7493 |

**Confusion matrix** (labels: `0` = bad credit, `1` = good credit):

```
Actual \ Predicted    0     1
0 (bad)              29    31
1 (good)             18   122
```

**Top global features by mean |SHAP|**: Checking Account Status (0.819), Credit Amount (0.452), Loan Duration (0.361), Loan Purpose (0.320), Savings Account Balance (0.304).

## Known Limitations

1. **Modest default recall (0.48)**: The training set is class-imbalanced (~70% good, 30% bad). No SMOTE or cost-sensitive weighting was applied — a deliberate scope choice for this assignment. Recall would improve with threshold tuning or resampling.

2. **Age-band disparate impact — `<25` group**: Under the four-fifths rule the `<25` age band (approval rate 36%, ratio 0.50 to the `60+` reference group) is flagged. This likely reflects data bias (shorter credit histories, smaller savings for young applicants) rather than model bias. Additionally, the `60+` reference group has only 7 test samples — too few for statistically reliable conclusions; treat with caution.
